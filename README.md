# DFU Insight — Downloads

Context-aware wound-image analysis (wound segmentation, periwound ring, wound-type prediction with conformal prediction sets and Grad-CAM). Runs fully offline.

| Platform | Download | Notes |
|---|---|---|
| **Android 7.0+** | [DFU-Insight-Android.apk](https://github.com/cbrethick/DFU-Insight/releases/download/v1.0.0/DFU-Insight-Android.apk) (758 MB) | Install the APK (allow "install unknown apps"). Models run on the phone; no internet needed. About a minute per analysis; 6 GB RAM recommended. |
| **Windows 10 / 11 (64-bit)** | [DFU-Insight-Windows-x64.zip](https://github.com/cbrethick/DFU-Insight/releases/download/v1.0.0/DFU-Insight-Windows-x64.zip) (1.37 GB) | Unzip, open the folder, start `DFU Insight.exe`. No installation. About 3 GB free memory. |
| **macOS, Apple Silicon** | [DFU-Insight-macOS-AppleSilicon.zip](https://github.com/cbrethick/DFU-Insight/releases/download/v1.0.0/DFU-Insight-macOS-AppleSilicon.zip) (1.30 GB) | Unzip, move `DFU Insight.app` to Applications. Not signed by Apple: first time, right-click → **Open** → **Open**. Intel Macs not supported. |
